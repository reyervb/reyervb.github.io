add info to [dates](https://github.com/reyervb/reyervb.github.io/blob/main/_data/dates.yml) it's located in root folder _data

add works:
works are in folder [_posts](https://github.com/reyervb/reyervb.github.io/tree/main/_posts) , have to be written in the format with a date. the latest date will be the top of the works menu.
future works are in folder [_drafts](https://github.com/reyervb/reyervb.github.io/tree/main/_drafts)

add post: 
1. copy raw data from another post 
2. go to the _posts folder, right above click button add file - create new file. paste the raw data
   *important! keep the format as is, so with the minuses top/below the gallery_name. otherwise it won't work.*
3. the name of the gallery :keep it short, only alphabetic characters or numbers. if there is no gallery, remove gallery_name totally. do not remove the minuses.
4. create folder with this name under [assets/img](https://github.com/reyervb/reyervb.github.io/tree/main/assets/img) and add images. they will appear in the post (do not put strange characters (underscores/etcetc) in the images)
5. add text: ## will be in right top, and bold. without is in normal format.
              text this is written in [markdown](https://www.markdownguide.org/basic-syntax/) keep in mind to not use h1 (#) or h2(##). these are formatted in the code.
