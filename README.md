text this is written in [markdown](https://www.markdownguide.org/basic-syntax/) 
please do not use  #(h1) or ##(h2). these are formatted in the code.

- add info to [dates](https://github.com/reyervb/reyervb.github.io/blob/main/_data/dates.yml) 
- edit [about](https://github.com/reyervb/reyervb.github.io/blob/main/about.md)
- u can copy the raw data of 'about.md' and add a file in the root to make another page. use the .md extension.  
  the 'title:' is h1. change this one to your new title and it will appear vertical
  *important! keep the format as is, so with the minuses top/below the gallery_name. otherwise it won't work.*  
  add the page with a html (not md!) extension in the [navigation](https://github.com/reyervb/reyervb.github.io/blob/main/_data/navigation.yml)  

add works:
works are in folder [_posts](https://github.com/reyervb/reyervb.github.io/tree/main/_posts) , have to be written alike the other files: first date and after the date the title of the work. it will be represented like this in the works submenu, without the date.  
the last date will be the top of the works menu and the earliest in the bottom.  
future works are in folder [_drafts](https://github.com/reyervb/reyervb.github.io/tree/main/_drafts)

add post: 
1. copy raw data from another post 
2. go to the _posts folder, right above click button add file - create new file. paste the raw data
3. the name of the gallery :keep it short, only alphabetic characters or numbers. if there is no gallery, remove gallery_name totally. do not remove the minuses.
4. create folder with this name under [assets/img](https://github.com/reyervb/reyervb.github.io/tree/main/assets/img) and add images. they will appear in the post (do not put strange characters (underscores/etcetc) in the images)
5. add text. text with ## in front of it will be in bold and in  the right top
